# 🗂️ Flash Card Project

A simple flash card application built using Python and Tkinter to help users learn French vocabulary.

## ✨ Features

* Displays random French words.
* Automatically flips the card to show the English translation.
* Marks known words and removes them from future practice.
* Saves learning progress.

## 🛠️ Technologies Used

* Python
* Tkinter
* Pandas

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/Prathammunot73/Flash_Card_Project.git
```

2. Install the required package.

```bash
pip install pandas
```

3. Run the project.

```bash
python main.py
```
