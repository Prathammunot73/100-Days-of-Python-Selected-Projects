# Snake Game

A classic Snake Game built using Python and the Turtle graphics library.

## Features

* Snake movement using arrow keys
* Food spawning at random locations
* Score tracking
* Snake grows when food is eaten
* Game over on wall collision
* Game over on tail collision

## Technologies Used

* Python
* Turtle Graphics
* Git & GitHub

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Prathammunot73/snake-game.git
   ```

2. Open the project folder.

3. Run:

   ```bash
   python main.py
   ```

## Controls

* ↑ Up Arrow
* ↓ Down Arrow
* ← Left Arrow
* → Right Arrow
