# Boston House Price Prediction – Multivariable Regression & Valuation Model

A machine learning project focused on predicting house prices using multivariable linear regression and evaluating the model's performance.

## 📌 Project Overview

This project explores the relationship between housing characteristics and property prices using the Boston housing dataset.

The analysis includes data exploration, visualization, multivariable linear regression, log transformation, model evaluation, residual analysis, and property price prediction.

## 🎯 Objectives

- Explore and understand the housing dataset
- Analyze relationships between housing features and property prices
- Build a multivariable linear regression model
- Evaluate model performance using R-squared
- Compare actual and predicted prices
- Analyze model residuals
- Use log transformation to improve the regression analysis
- Predict property prices using the trained model

## 📊 Analysis Performed

- Residual analysis
- Model evaluation
- Out-of-sample prediction

## 📈 Model Evaluation

The regression models are evaluated using **R-squared** and visual analysis of predicted values and residuals.

The notebook also compares the original price model with the log-transformed model.
