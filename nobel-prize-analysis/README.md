# 🏆 Nobel Prize Analysis

An exploratory data analysis project that investigates Nobel Prize winners using Python, Pandas, NumPy, Matplotlib, Seaborn, and Plotly.

The analysis explores patterns and trends in Nobel Prizes across different years, countries, categories, genders, and winner ages.

This project was developed as part of my learning journey through the 100 Days of Code: The Complete Python Pro Bootcamp by Dr. Angela Yu.

## 📌 Project Overview

This project analyzes Nobel Prize winner data to answer questions such as:

- Which countries have produced the most Nobel Prize winners?
- Which Nobel Prize categories are most common?
- How has the number of Nobel Prizes changed over time?
- What is the gender distribution among Nobel Prize winners?
- At what age do Nobel Prize winners typically receive their prize?
- How has the average age of Nobel Prize winners changed over the years?
- Which countries and categories have shown significant trends over time?

## 📊 Analysis & Visualizations

The project includes:

- Nobel Prizes awarded by year
- Nobel Prizes by category
- Nobel Prize winners by country
- Gender distribution of winners
- Country and category comparisons
- Moving average analysis
- Winner age analysis
- Winning age trends over time
- Interactive visualizations using Plotly
- Statistical visualizations using Seaborn and Matplotlib

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data cleaning and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Plotly** – Interactive visualizations
