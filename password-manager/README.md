# 🔐 Password Manager

A simple Password Manager built using Python and Tkinter to generate and save website login credentials.

## ✨ Features

- Generate strong random passwords.
- Save website, email, and password details.
- Store credentials in a text file.
- Copy generated passwords to the clipboard.
- User-friendly graphical interface.

## 🛠️ Technologies Used

- Python
- Tkinter
- Pyperclip

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/Prathammunot73/Password_Manager.git
```

2. Install the required package.

```bash
pip install pyperclip
```

3. Run the project.

```bash
python main.py
```
