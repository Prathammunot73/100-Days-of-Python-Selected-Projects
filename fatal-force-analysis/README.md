# Fatal Force Analysis

An exploratory data analysis project analysing fatal police shootings in the United States using demographic, socioeconomic, and incident-level data.

This project was created as part of the **100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

---

## 📌 Project Overview

The project combines police fatality data with US census data to explore relationships between police killings, race, education, poverty, age, gender, and other demographic factors.

The analysis uses Python, Pandas, Matplotlib, Seaborn, and Plotly to clean, analyse, and visualize the data.

---

## 🔍 Analysis Performed

- Explored and cleaned multiple datasets containing police fatality and US demographic data
- Analysed poverty rates and high school completion rates across US states
- Examined police killings by race, gender, age, mental illness, and armed status
- Analysed the distribution of police killings across cities and states
- Compared racial population shares with recorded police killings in major cities
- Analysed police killings over time using time-series visualization
- Created interactive and statistical visualizations using Plotly, Matplotlib, and Seaborn

---

## 📊 Visualizations

The project includes:

- Bar charts
- Donut charts
- Box plots
- Histograms
- KDE plots
- Regression plots
- Choropleth maps
- Time-series charts
