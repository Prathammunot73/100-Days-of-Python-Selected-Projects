# Space Race Analysis 🚀

An exploratory data analysis and visualization project analysing space missions from the beginning of the Space Race in 1957 through 2020.

This project was created as part of the **100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

---

## 📌 Project Overview

The Space Race led to thousands of rocket launches and missions involving countries and organisations around the world.

In this project, I analysed a dataset containing historical space missions to understand:

- Which organisations launched the most missions
- How many rockets are active or retired
- Mission success and failure rates
- The cost of space launches
- Which countries conducted the most launches
- How launch activity changed over time
- Which months were most popular for launches
- How launch prices changed over the years
- The dominance of major space organisations
- The USA vs USSR during the Cold War Space Race

The analysis uses Python, Pandas and Plotly to explore and visualise the data.

---

## 📊 Dataset

The dataset was scraped from **Next Spaceflight** and contains space missions dating back to the beginning of the Space Race in 1957.

### Original Dataset Features

| Column | Description |
|--------|-------------|
| Organisation | Organisation responsible for the mission |
| Location | Launch location |
| Date | Date of the mission |
| Detail | Rocket and mission details |
| Rocket_Status | Whether the rocket is active or retired |
| Price | Launch price in USD millions |
| Mission_Status | Mission outcome |

The original dataset also contained two index columns, which were removed during data cleaning.

## 🔍 Analysis Performed

- Explored and cleaned historical space mission data
