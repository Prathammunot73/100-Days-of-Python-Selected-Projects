# 📊Google Trends Data Visualization

This project analyzes Google Trends data using Python, Pandas, and Matplotlib to identify trends and relationships between Google search interest and real-world data.

## Project Overview

In this project, I analyzed:

- Tesla search trends vs Tesla stock price
- Bitcoin search trends vs Bitcoin price
- US Unemployment Benefits search trends vs unemployment rate

The project demonstrates data cleaning, time series analysis, resampling, rolling averages, and data visualization.

## Features

- Data cleaning with Pandas
- Handling missing values
- Time series analysis
- Monthly data resampling
- Rolling mean calculations
- Line plots and scatter plots
- Correlation between search trends and real-world metrics

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The project uses the following datasets:

- TESLA Search Trend vs Price
- Bitcoin Search Trend
- Daily Bitcoin Price
- US Unemployment Benefits Search vs Unemployment Rate

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Prathammunot73/Google-Trends-Data-Visualization.git
```

2. Install the required libraries

```bash
pip install -r requirements.txt
```

3. Open the notebook

```bash
jupyter notebook
```

4. Run all cells.
